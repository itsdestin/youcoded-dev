9Settings → Permissions — the mode explainer. The reference card at the top of the Permissions page.

Permission modes

Ask first — Checks with you before changing a file or running a command. Reading and searching never interrupt you.

Auto edit — Changes files without asking. Still checks before running a command.

Full auto — Works without checking with you, so you can leave it running. It still asks before:

  • Deleting files or folders
  • Sending your work to a shared code repository
  • Throwing away changes you haven't saved anywhere else
  • Anything needing your computer's administrator password
Each conversation has its own mode. Change it from the bar at the bottom of the chat.

11The (i) explainer on the Permissions page. Opens from the (i) button in the page's title bar.

The assistant asks you before doing anything that changes your computer — running a command, editing a file. Choosing “Always allow” when it asks is what puts something on this list. How often it asks in the first place is a separate setting, explained below.

How much it asks

Each conversation has its own mode, and you can change it part-way through from the bar at the bottom of the chat.

  • Ask first — asks before anything that changes your files or runs a command. Reading and searching never ask.
  • Auto edit — edits files without asking, but still asks before running commands.
  • Full auto — doesn't ask at all, apart from the things it always asks about. Use it when you're watching.

Presets

When you start a conversation you pick a preset, which decides the starting mode.

  • Assistant — starts cautious and asks about most things.
  • Coder — starts able to edit files without asking, since that's most of the work.

Things it always asks about

The short list on this screen asks every time, whatever mode you're in — even Full auto, even in a folder where you've approved everything else. They're the things that are hardest to undo.

If you choose “Always allow” on one of these, the app asks you to confirm, and from then on that one exact thing stops asking. It appears in the list like any other approval, and removing it puts the question back.

Approvals you've already given

Most approvals belong to the folder you were working in when you gave them — the same request in another folder asks again. The exception is your own specialists: allowing one of them applies in every folder, under “All projects”.

Removing an approval doesn't undo anything it already did. It only means you'll be asked the next time.

Approvals you gave Claude Code

Conversations running on Claude Code keep their own separate list of approvals, which this screen doesn't manage. You can change those in Claude Code's own settings.

12The (i) explainer on the Specialists page — the part about permissions.

Read-only vs can edit

A read-only helper can look at files and search the web, but can't change anything or run commands. A helper that can edit is limited to the folder it was hired for. Either way, secrets and anything outside that folder still ask you — and for helpers that can edit, so does deleting things. Approving a hire is what grants this; the card in the chat says exactly what before you say yes.

Your changes

Fills in when you press Copy my changes — only the sentences you altered, old → new.
