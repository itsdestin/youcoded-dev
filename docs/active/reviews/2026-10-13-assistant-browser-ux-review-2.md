## Triage (implementing session, 2026-10-13)

- U1 accepted — on a narrow window the panel repeats the browser's question at its top.
- U2 accepted — "Stop browsing in this chat" (the practice app's fake doesn't close tabs; the real app empties the panel).
- U3 rejected — removing a site is undone by one "Always allow" the next time; a confirm per row adds friction for nothing lost.
- U4 accepted — Settings asks first, like the panel, when pages are open.
- U5 accepted — no Show window button while the browser is in an error state.
- U6 accepted — "…another YouCoded window is already using it. Close the other YouCoded and try again."
- U7 accepted — "Browser to use" / "Which browser on this computer the assistant uses."
- U8 accepted — "Uses your open Chrome and your sign-ins, so the assistant can act as you. It asks before opening each new site."
- U9 accepted — "I can't do this"; the card's window button is now "Show window", the same name as the panel's.
- U10 accepted — "Don't allow".
- U11 accepted — title "Browser needed", body says it once.
- U12 accepted (wording) — "It still asks before sending, buying or deleting." Contrast of secondary buttons over a wallpaper is the theme's glass, shared by every card; rejected here.
- U13 rejected — same glass as every other chat card; a theme-wide question, not this feature's.
- U14 accepted — "The assistant wants to open a page on this computer or your home network (host:port)." + "These pages can control your router, your devices or programs you're running."
- U15 accepted — one description for both switch states (no jump); the sign-in row's hint wraps instead of cutting.
- U16 rejected — the dialog scrolls and fades at its edge like every Settings dialog.
- U17 accepted — the list under the picture is labelled "Tabs N".
- U18 accepted — "Private: separate from your own browser and sign-ins. Sites you sign into here stay signed in next time. Press Show window to watch it in a real window."
- U19 rejected — the four words are the spec's status set; each is plain alone.
- U20 rejected — a start error and a missing browser already reach the chat (the assistant's result and the no-browser card); the header button shows once a chat has used the browser.
- U21 accepted — the confirm's button now says "Show window" / "Hide window".
- U22 already handled — no pause at 2000 rows.
