## 5. Monte Carlo of the 3-guess attack on a deliberately tiny code (checks the theory with the real protocol)
  2-digit code, 3000 trials x 3 real protocol attempts: attacker won 111 times; theory 3/100 = 3.00% -> 90 +/- 9.3 (23.18 ms per attempt)
  ok  measured win rate matches 3/N within 4 sigma
