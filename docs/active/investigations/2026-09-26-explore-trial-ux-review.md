## About the tool

`scroll up N` / `scroll down N` — I expected `N` to mean "scroll N notches," but it's actually a control number to scroll over (like `click N`). Passing `scroll up 20` right after a step where control 20 was "All Sessions" silently scrolled that button instead of the chat, with no error — it just printed `scroll button "All Sessions"`. The kit's one-line description ("The mouse wheel, over control N or the middle of the window") reads like N could be either a count or a target; it's only a target. Cost me one wasted step until I dropped the number and used plain `scroll up`.
