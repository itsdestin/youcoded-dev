P-15 — Two dialogs have no title and no ✕; two footers wrap measured

The problem

Report a bug / Feature request opens as a bare box: a Bug/Feature switch, a text area and a Continue button. No title says what it is, and there is no ✕ — Escape is the only way out. Donate is the same: three lines of copy and two buttons, no title row, no ✕. Every other dialog in the app has the same header (title · optional ⓘ · ✕), so these two are the exceptions.

In the Close session prompt the footer is the tallest row of the dialog: "Don't show again" wraps onto two lines beside its toggle, and the primary button breaks into "Close / session". Both happen in every theme (the light crop below shows it most clearly).

What I'd change

  • Give both dialogs the shared header: "Report a bug" / "Support YouCoded" as the title, a ✕ on the right. Same component every other dialog already uses; no new styling.
  • Close-session footer: the buttons go to the small size the rest of the dialog uses, and "Don't show again" becomes its own one-line row above the buttons instead of squeezing beside them.
  • Also in this item (small): the About and Permissions dialogs cut their content off with no scrollbar or fade to say there is more — add the fade every other scrolling dialog has.

What you'd notice, and the risk

Two dialogs gain a title row and a ✕ (a few pixels taller). The close-session prompt gets a little taller by one row and the buttons stop wrapping. Nothing else moves. Risk: essentially none — this is applying the existing dialog anatomy to the two places that skipped it.

P-18 — Tool cards: a typed "|" in every header, and the AskUserQuestion card's odd header mixed

The problem — measured part

Every tool card's header reads ⊘ | Reading ChatView.tsx ↳ components/. That | is a literal text character, not a divider: it is the wrong colour on some themes, it is read aloud by screen readers, and it doesn't line up with the icon. It appears on every tool call in every conversation, so it is the most-seen glitch in the app.

The problem — judgment part

The AskUserQuestion card (when the assistant asks you to choose) uses a different header from its siblings: ⓘ | Framework ▾ instead of glyph · title · ↳ first question · chevron, and its option rows use their own row style. It works; it just doesn't look like the card next to it. This is a consistency call, not a defect.

What I'd change

  • Measured: replace the typed | with a real 1-pixel divider element in the header — same position, drawn with the theme's edge colour. Invisible change except that the bar sits straight and takes the theme's colour.
  • Judgment (can skip): AskUserQuestion adopts the standard header (glyph · "Question" · ↳ the first question · chevron on the right) and its option rows use the same row style as the other cards' rows; Submit stays a primary button.

What you'd notice, and the risk

The divider: nothing, except the pipe character is gone. The AskUserQuestion header: that card looks like the others; risk is that people are used to its current shape — it's the card they interact with most.

P-10 — Status bar: 10px text and a two-row wrap on phones; the orange model chip mixed

The problem — measured part

The status bar's chip text is 10px. The design guide's floor for anything informational is 11px (G-5) — the status bar is the only surface still below it. At phone width (390px) the chips wrap onto a second row with the theme chip orphaned on its own line, which pushes the composer up.

The problem — judgment part

The model chip (Sonnet | Auto Effort) has an orange outline while every other chip is grey, so the model reads as a warning. The theme-name chip is drawn like a button but is a label. Both are choices, not defects.

What I'd change

  • Measured: text goes from 10px to 11px (the bar gets ~2px taller); at phone width the chips collapse to their icons before they are allowed to wrap, so the bar stays one row.
  • Judgment (can skip): all chips take the same grey outline and the model chip shows the model's icon instead of the orange border; the theme chip becomes a plain label with the cycle control appearing on hover.

What you'd notice, and the risk

Slightly larger status text everywhere and no second row on phones. If you also take the judgment part: the orange outline disappears — if you rely on that orange to spot the model at a glance, say so and it stays.
