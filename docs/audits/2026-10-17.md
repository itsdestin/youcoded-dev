## Security triage and explicit decisions

Fresh npm audit reported 30 affected dependency entries (1 critical, 12 high,
16 moderate, 1 low), not 30 demonstrated product exploits. Static reachability review
identified the DOCX preview's call to Mammoth's older embedded XML parser before HTML
sanitization. Reported parser denial-of-service exposure is relevant to a user-opened
crafted DOCX; code execution and a zero-interaction exploit were not demonstrated.
Destin explicitly chose to release current behavior and file the fix for later;
work item **#161** records the risk, evidence and embedded-bundle caveat. No parser,
lockfile or dependency upgrade was made.

The reviewed MCP client does not configure the OAuth provider implicated by its
advisory, and the critical proxy/server path was not demonstrated reachable. Several
other production transitive findings remain unverified, not declared safe. This review
is not blanket security clearance or a legal opinion.

Destin explicitly deferred Developer ID signing/notarization to **1.3.2 (#28)** and
authorized the current 1.3.1 app release. Existing ad-hoc Mac seal and packaged-Office
checks remain. Existing website demos were retained; no refresh is claimed. Unfinished
feature/refactoring backlog remains open rather than being represented as shipped.

## Unverified scope
