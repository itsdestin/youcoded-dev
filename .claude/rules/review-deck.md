# Review deck — the one surface Destin answers on

`python3 scripts/ui-review/review-cards.py <command> <spec.json>`. Every question, choice,
approval and sign-off is a step.

## Pick the kind, copy `scripts/ui-review/templates/<kind>.json`

| You want Destin to… | Kind | Spec shape | He answers |
|---|---|---|---|
| approve a change he can see | **Approve** | `crop` + `changed` + `notice`, two runs | Yes keep it / No revert it |
| approve something not built yet, over today's picture | **Brief** | same, one run (`runs: {today}`) | Yes build it / No leave it |
| pick between several pictures of ONE thing | **Choice** | `variants[]`, each with a `crop` | pick one / None of these |
| pick between written options over one picture | **Decide** | `crop` + `highlight` + `options[]` | pick one |
| judge motion, hover or a transition | **Clip** | `clip`, from `record-pair.sh` | Yes / No |
| operate the real thing — drag, hover | **Live** | `live` panes, `variants` for pick-one | Yes / No, or pick one |
| ask before anything is drawn, or decide in words | **Question** | `words: true` + the parts below, page markers | Yes / No / Don't know, or pick one |
| sign off the definition of done | **Contract** | `rows[]` | Yes that is done / No |
| accept the graded contract | **Acceptance** | generated by `review-cards.py acceptance` | Yes accept / No |

Other + a note is on every step. Several designs of one thing are ONE Choice step, never a
yes/no each. A step whose picture exists in one theme carries its own `themes`.

## A question deck is pages he scrolls
**Invariant:** questions share one page until a marker (`{"id", "page", "intro"}`) starts the
next; add one only where the thinking shifts. A deck with a contract step is never paged. **Why:** "my mindset should stay in the same place for each set of
questions" (Destin, 2026-09-04). **Guard:** `test_words.py`.

## A question carries its four parts as fields
**Invariant:** `today`, `problem`, `proposal`, and `options[]` with `pros`, `cons`, at most one
`recommended: true`. "Today: … Pro: …" in a sentence, or "(recommended)" in a label, is refused
by field name. **Why:** 28 of 28 options drifted in two days. **Guard:** `test_words.py`.

## Look at it before he does
**Invariant:** `preview <spec>`, then READ `preview/contact.png`, before `serve`. A deck he
already answered is re-served with `serve --no-build`, never rebuilt — rebuilding a historical
deck "fixes" the record of a past decision. **Why:** four defective decks went out in one day.
**Guard:** none — candidate.

## A change under `deck/` is reviewed on a deck
**Invariant:** an edit to `page.css`, `page.js`, `page.html.tmpl` or `deck/fixture/` ships only
after `selfie` has shown him before and after it — and `selfie` leaves every `headline`/`changed`
a `TODO:` the build REFUSES, so you write what moved and what he will notice, per step.
**Why:** he answered five generated steps "no idea what i'm supposed to be looking at".
**Guard:** `test_cli.py`.

## The deck opens on the theme his app is on
**Invariant:** never hand-order `themes` — `build`/`serve` read the app's; `--theme` overrides,
`"theme": "fixed"` pins. **Why:** every deck opened on Midnight whatever his app was on.
**Guard:** `test_spec.py`.

## The link goes in chat as the last line of the turn
**Invariant:** `serve` prints `[deck] http://…` and opens nothing; paste it last, stop.
**Why:** he opens it when ready (Destin, 2026-09-05). **Guard:** none — candidate.
